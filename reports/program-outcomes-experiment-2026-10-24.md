# Гипотеза: конкретные навыки внутри программы

## Основание

Пакет `3be7954` дал 41/102 (40,2%) против большого контроля 154/502 (30,7%). Это перспективный, ещё не подтверждённый сигнал (p=0,064). Вместо повторения того же варианта выбран следующий опыт.

Предполагаем, что короткие списки конкретных навыков внутри подробной программы помогут лучше понять содержание курса и чаще перейти к реальному заполнению. Это гипотеза о подаче содержания, а не установленный критерий симулятора.

## Изменение

- По три пункта в каждом из шести раскрываемых модулей: всего 18.
- Пункты пересказывают уже имеющиеся темы. Новые услуги, сроки и гарантии результата не добавлены.
- Для обеденного разбора заголовок «Что обсудим», для практических модулей — «Что разберёте и отработаете».
- Исходные абзацы, заголовки модулей, расписание, цена, форма, автофокус и порядок разделов сохранены.
- HTML вне новых списков совпадает с контролем с точностью до пробелов. CSS новых списков влияет только на раскрытое содержимое.

## Измерение

Основная метрика — серверные заявки / визиты; дополнительная — реальный ввод после CTA. Контроль для этой конкретной правки — `3be7954` с 41/102. Большой прогон `0e927f5` с 154/502 — дополнительный ориентир, но относительно него изменился весь пакет, а не только списки.

Новые события `program_open` / `program_close` содержат номер `module_1..module_6`. Они означают раскрытие/закрытие, **не доказывают чтение**. При начальной свёртке событий открытия нет. Отправляются в прежний behavior-трекер без значений полей.

Метки диагностики: `program-outcomes-v1` / `price3900-program-outcomes`; схема `preinput-v1`. Автофокус по-прежнему отделён от реального ввода.

## Прогон

Redeploy новой версии, затем один запуск с заранее выбранным объёмом; предпочтительно 500 визитов. Дождаться окончания без остановки по проценту. Сохранить выгрузки до следующего Redeploy.

Проверять долю начавших ввод и серверный успех. Раскрытия анализировать отдельно по посетителям, модулям и исходу; не считать корреляцию раскрытия с заявкой доказательством причинности. Контроль из 102 визитов ограничивает точность даже при 500 новых визитах. Поскольку положительная предыдущая версия ещё не повторена, результаты обоих опытов остаются исследовательскими.
