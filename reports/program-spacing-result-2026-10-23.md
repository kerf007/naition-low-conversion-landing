# Результат: компактность программы

## Конверсия

Публичная версия совпадает с `33a1d49` по HTML, CSS, основному и диагностическому JS. Сервер и лидерборд показывают 103 визита, 22 заявки, **21,4%**, место 4. Рекомендованный объём 500 визитов в выгрузке отсутствует. Происхождение трёх визитов без CTA не установлено, они включены в серверный знаменатель.

| Метрика | Контроль `a56d22d` | Компактная программа `33a1d49` |
| --- | ---: | ---: |
| Заявки / серверные визиты | 30 / 102 | 22 / 103 |
| Конверсия | 29,4% | 21,4% |
| Нажали CTA и увидели первое поле | 100 | 100 |
| Начали ввод после CTA | 30 | 22 |
| Отправили среди начавших ввод | 30 / 30 | 22 / 22 |
| Не начали ввод после CTA | 70 | 78 |

Разница −8,05 п.п., 95% интервал разницы по Ньюкомбу −19,71…+3,87 п.п. Двусторонний точный тест Фишера p=0,202; интервал Уилсона новой конверсии 14,5–30,2%. Положительного эффекта не наблюдаем, но доказанного вреда тоже нет. Небольшие последовательные выборки без рандомизации не позволяют приписать изменение только отступам.

Прогон `3858c95` с 137/501 (27,3%) — дополнительный ориентир: p=0,222 при сравнении с текущим результатом. Он не заменяет основной контроль: там были другая прокрутка и меньше диагностики.

## Диагностика

- Все 100 CTA-попыток завершены, без пропусков событий и лимитов записи.
- 22 попытки взаимодействия с полями → 22 начала ввода → 22 заявки. Ошибок валидации/отправки нет.
- 68 отказавшихся имели доступное первое поле в последнем снимке, но не пытались нажать.
- Ещё у 10 поле было меньше чем наполовину видно перед уходом. У всех 10 ранее был снимок с доступным полем. Это не доказательство отказа из-за обрезания.
- Все 78 не начавших ввод хотя бы раз имели доступное первое поле после CTA.
- Во всех 100 CTA-визитах сохраняются события колеса прокрутки и возврат к форме.
- Медиана последнего прибытия → фокус 0,497 с, прибытия → уход без фокуса 2,232 с. Прибытие фиксируется после 400 мс без прокрутки; эти времена не показывают момент принятия решения.
- Типичная высота страницы 7387 px против 7705 px в контроле: компактный CSS применился. Геометрия формы правкой не менялась.

Главная потеря по-прежнему до взаимодействия с полями. Улучшения начала ввода от уменьшения отступов не наблюдаем.

## Разделение версий и полнота

Сырой экспорт содержит 104 клиентских ID. Один принадлежит старой вкладке `3858c95-instant`: нет нового page_view, события начинаются с seq=28. Это тот же незавершённый ID, который был в предыдущем прогоне. Его поздние события после Redeploy исключены из аналитики новой версии.

После отбора: 103 ID с page_view, все совпадают с 103 ID диагностики `program-spacing-v1` / `price3900-program-spacing`. Из них 102 имеют событие ухода; единственный незавершённый визит не нажимал CTA. Серверный знаменатель оставлен 103, из него никого не вычитали. Все текущие визиты имеют desktop-телеметрию.

В дашборде смешанные диагностические выгрузки теперь разбиваются по версии трекера, интерфейса и эксперименту. Старая вкладка показана отдельно; её пропуск seq не относится к новому прогону. Добавлен тест этого случая, все 7 тестов проходят.

## Решение

Гипотеза о пользе меньших отступов не получила поддержки. Не объявляем вариант победителем и не используем его как подтверждённое улучшение для следующих изменений.

Для следующего содержательного эксперимента рекомендован возврат прежних отступов. Затем можно отдельно менять текст программы — фактор, который сопровождал исторический скачок, но был смешан с другими правками. Возврат и новый текст в этом анализе не внесены. Если требуется установить именно эффект отступов, нужен дополнительный контроль и вариант с заранее выбранным объёмом: увеличение только текущей выборки не устраняет неопределённость контроля из 102 визитов.
